# Assist Toolkit

A unified suite of locally developed security, reconnaissance, and CTF automation tools.

## Included Modules

### 1. InfraGraph (`/infragraph`)
Attack surface and takeover intelligence engine designed for automated domain discovery, DNS/cloud asset mapping, and security analysis.

### 2. Recon Engine (`/recon-engine`)
Automated bug bounty recon pipeline featuring subdomain enumeration, diff alerting, and interactive web dashboard.

### 3. CTF Automation Suite (`/ctf-suite` & `/ctf`)
Specialized tools and automation scripts for CTF challenges:
- `webrecon.py` — Web reconnaissance and endpoint inspection
- `sweep.py` — Automated forensic artifacts extraction and packet analysis
- `triage.py` — Quick binary & file inspection triage
- `reverse.py` — Binary decompilation and analysis
- `decode.py` — Multi-layer payload decoding engine
- `ctf.sh` & dashboard — CTF workflow controller and local dashboard
